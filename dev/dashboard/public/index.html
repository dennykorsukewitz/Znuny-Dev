About Znuny-Dev

GPL-3.0

Znuny-Dev is a local development environment for Znuny. It creates and manages containerized framework instances, links packages and development tools, and provides this dashboard to start, stop, inspect and open your instances.

Everything runs on your machine via Docker Compose and the zd command line helper.
